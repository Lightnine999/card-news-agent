# 카드뉴스 워크플로 제작 키트

## 앱 실행하기

주제를 넣으면 조사 → 후보 선택 → 질문 답변 → 스토리보드 → 배경 그림까지 이어져요. 글자를 얹은 카드 완성과 내려받기는 아직 없어요(구현 5단계).

처음에는 **모의 모드**로 켜 보는 걸 권해요. 실제 검색 없이 정해진 예시 데이터로 화면 흐름만 보여 줘서 사용량이 들지 않아요. 모의 데이터일 때는 화면 맨 위에 노란 띠 **"모의 데이터예요. 실제 검색 결과가 아니에요."**가 늘 보여요.

> macOS 기준이에요(Linux도 같아요). Windows에서는 아직 확인하지 않았어요.

### 1. 터미널 열기
- macOS: `command + space`를 누르고 **터미널**을 입력해 엔터.

### 2. 처음 한 번만: 준비하기
1. uv가 있는지 확인해요. 버전 번호가 나오면 다음 단계로 가요.
   ```bash
   uv --version
   ```
   `command not found: uv`가 나오면 [uv 공식 설치 방법](https://docs.astral.sh/uv/getting-started/installation/)대로 설치하고, **터미널 창을 닫았다가 새로 열어요.**
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```
2. 앱 폴더로 이동해요. 이 폴더(`card-news-workflow-kit`)를 둔 곳으로 가면 돼요. 예를 들어 홈 폴더 아래 `aiffel_work`에 있다면:
   ```bash
   cd ~/aiffel_work/card-news-workflow-kit
   ```
   제대로 왔는지는 `ls`를 쳐서 `pyproject.toml`과 `README.md`가 보이는지로 확인해요.
3. 필요한 프로그램을 설치해요. 처음엔 1~2분 걸릴 수 있어요. 맞는 Python이 없으면 uv가 알아서 받아요.
   ```bash
   uv sync
   ```

### 3. 켜기 (모의 모드)
2번에서 이동한 폴더에서 입력해요.
```bash
CARDNEWS_ENGINE=mock uv run cardnews
```
이렇게 나오면 켜진 거예요. **이 터미널 창은 닫지 말고 그대로 둬요.** 창이 켜져 있는 동안만 앱이 돌아가요.
```
엔진: mock  ·  열기: http://127.0.0.1:8765
끄려면 이 창에서 Ctrl+C를 누르세요.
```

### 4. 브라우저에서 열기
브라우저(Chrome, Safari 등) 주소창에 아래 주소를 입력해요.
```
http://127.0.0.1:8765
```
1. 주제 입력칸에 `AI 최신소식`을 넣고 **[조사 시작]**을 눌러요.
2. 진행 화면이 몇 초 뒤 후보 목록으로 바뀌면, 후보를 **1~3개** 체크하고 **[다음 단계]**를 눌러요. 체크한 것은 새로고침해도 남아요.
3. "어떤 독자에게 전달할까요?" 질문이 나오면 하나를 고르고 **[답변 보내기]**를 눌러요. ⭐는 추천일 뿐이라 미리 선택돼 있지 않아요.
4. 편집 제안과 스토리보드가 나와요. **[이대로 승인하고 제작]**을 누르면 카드마다 배경 그림이 만들어져요(모의 모드는 단색 모의 그림).

모의 모드에서 다른 상황을 보려면 주제에 이 말을 넣어요.
- `적음` → 후보가 3개만 나와서 "30일로 넓힐까요?" 질문이 떠요
- `실패` → 검색 실패 오류 카드와 재시도 버튼이 떠요
- `기간밖` → 조사 기간보다 오래된 후보를 앱이 빼고 "조사 기간 밖 후보 1개를 뺐어요"를 보여 줘요

### 5. 끄기
앱을 켠 **터미널 창을 클릭한 다음 `control` 키를 누른 채 `C`**를 눌러요(Mac에서도 `command`가 아니라 `control`이에요). 이렇게 나오면 다 꺼진 거예요.
```
[worker] 종료 신호를 받아서 작업 프로세스를 끝내요
서버를 껐어요.
```
조사나 그림 만들기가 돌던 중이었다면 그 작업(Claude CLI·agy)도 함께 멈춰요. 다음에 켜면 그 작업은 "서버가 다시 시작돼서 작업이 멈췄어요" 카드와 [이 단계 처음부터] 버튼으로 보여요. 끈 뒤에는 브라우저 탭을 닫아도 돼요.

### 6. 실제 검색으로 켜기
모의 모드에서 흐름을 봤다면, 실제 검색으로 켜 봐요. 3번처럼 앱 폴더에서 입력하는데, `CARDNEWS_ENGINE=mock`만 빼요.
```bash
uv run cardnews
```
- Claude Code CLI(`claude`)에 로그인돼 있어야 해요. 안 돼 있으면 화면에 "Claude CLI 로그인이 필요해요" 카드가 떠요. 그럴 땐 앱을 끄고, 터미널에서 `claude`를 실행해 로그인한 뒤 다시 켜요.
- 그림 만들기에는 Antigravity CLI(`agy`) 로그인이 필요해요.
- 실제 검색은 Claude 사용량이 들어요. 시험 때 CLI가 알려 준 추정으로는 한 프로젝트를 조사부터 스토리보드까지 진행하는 데 누적 약 $0.8~1.4였어요(실행마다 달라요). 그림은 카드 한 장마다 agy를 한 번 불러요.

### 문제가 생기면
| 보이는 것 | 할 일 |
|---|---|
| `command not found: uv` | 2번의 uv 설치 후 터미널 창을 새로 열어요 |
| `포트 8765을(를) 이미 다른 프로그램이 쓰고 있어요` | 앱이 이미 켜져 있는지 다른 터미널 창을 확인해요. 다른 프로그램이면 `uv run cardnews --port 8766`으로 켜고 `http://127.0.0.1:8766`을 열어요 |
| 브라우저에 "연결할 수 없음" | 앱을 켠 터미널 창이 아직 열려 있는지, 거기에 오류가 없는지 봐요 |
| `error: Failed to spawn: cardnews` (`No such file or directory`) | 앱 폴더가 아닌 곳에서 입력했어요. 2번의 `cd`부터 다시 해요 |

만든 프로젝트와 조사 기록은 앱 폴더 안 `data/`에 저장돼요. 끄고 다시 켜도 남아 있어요.

### 테스트

```bash
uv run pytest
```

### 파일 구성
- `cardnews/app.py` 웹 API · `service.py` 요청 규칙 · `pipeline.py` 엔진 결과 반영 · `worker.py` 작업 프로세스
- `cardnews/engines/` 엔진 연결: `claude_cli.py`(실행), `claude_prompts.py`(지시문), `claude_schema.py`(결과 형식·거르기), `mock.py`
- `static/` 화면 (빌드 단계 없는 HTML/JS)
- `data/` 실행 데이터. 커밋하지 않아요(.gitignore).
- 설계 문서: `DECISIONS.md`(결정 기록), `API_SPEC.md`, `SCREEN_FLOW.md`, `DESIGN.md`
